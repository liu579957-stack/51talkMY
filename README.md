# 马来西亚家长英语 · 销售学习卡

由 Excel 知识库《02_马来西亚客户知识库与术语总表》自动生成的学习网站，供英语基础较弱的销售顾问随时查词、听发音、做测验。

## 内容覆盖（全部 20 个 sheet）
- **单词/术语（14 类，共 212 条）**：课程与试听、老师相关、孩子英语能力、测评与学习反馈、课程内容与学习目标、套餐价格与付款、出勤请假与安排、设备与技术、决策与异议、本地表达、学校类型与年级、学科与校内场景、地域与客户背景、学习体系与考试
- **真实句式（20 条）**：听英文、看中文，练听力识别
- **Manglish（12 条）**：大马式中英夹杂识别，含 CC 建议与风险提示
- **公司问答（6 条）**：客户质疑真实性/地址时的标准应答与禁区红线
- **语言原则（6 组）**：不够自然 vs 更自然示例对照

## 功能
- **📅 每日打卡（首页）**：把 14 个分场景 + 真实句式/Manglish/公司问答排成 **DAY 1–17 学习路径**，每天一屏一个场景
  - 每张卡片：点英文听**发音**、看中文**含义**、看**应用场景**（家长说法 / 诊断重点 / 背景提示等）
  - 每词可「标记已学」，底部「完成今日打卡」记录进度
  - 顶部显示**连续打卡天数**、今日日期、总天数；自动跳到第一个未打卡的天
  - 打卡与「已学」状态存在浏览器本地（localStorage），关闭不丢失
- 点英文听发音（浏览器 TTS，自动识别中英文）
- 点「家长可能说」听中文例句
- 分类切换 + 关键词搜索
- 公司问答/特殊 sheet 的额外字段（全称、诊断重点、CC 可继续问、背景提示、禁止假设）均展示
- 生词/句式收藏（localStorage，本地保存）
- 随机测验（听英文选中文）
- 移动端友好、纯静态、无需服务器

## 重新生成
```bash
python build_site.py   # 读取 Excel -> 注入 template.html -> 输出 index.html
```

## 部署（GitHub Pages）
将 `site/index.html` 推到仓库，开启 Pages 即可。详见对话说明。
